# Feedback

ExecuSeal is pre-alpha. Feedback from AI application developers, security
engineers, platform teams, researchers, and operations users will shape the
public interfaces and benchmarks.

Use the GitHub feedback issue form for usability, integrations, policies,
documentation, false positives, and missing safe-use scenarios. Please include:

- your role and agent framework, if relevant
- the task you were trying to complete
- the expected and actual allow/review/block result
- a minimal synthetic or fully redacted reproduction
- version, operating system, Python version, and deployment mode
- the business or safety impact

Never include API keys, access tokens, personal information, customer data,
private prompts, internal URLs, or proprietary tool schemas. Replace them with
obvious placeholders before submitting.

Do not report a suspected bypass or vulnerability through a public feedback
issue. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability
reporting after the repository launches.
